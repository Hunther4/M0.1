# 📊 Research Metrics & Gradient Monitoring

- **Gini Index:** Measures expert load imbalance (0.0 = perfect balance, 1.0 = total inequality).
- **KL Divergence:** Router gate distribution divergence from uniform.
- **Gradient Statistics:** `grad_mean`, `grad_std`, `grad_max`, `grad_min`, `grad_sparsity`, `largest_grad_norm`, `layer_with_biggest_grad`.
